# Epic Voices: Literary Portfolio

Open `index.html` in any browser to view the site. No installation is needed.

## Pages

| File | Section |
|------|---------|
| `index.html` | I. Student Profile |
| `analyses.html` | II. Seven Literary Analyses |
| `masterpiece.html` | III. Favorite Literary Masterpiece (The Odyssey) |
| `learning.html` | IV. Summary of Learning |
| `reflection.html` | V. Personal Reflection |

Shared design and behavior live in `assets/styles.css` and `assets/main.js`.

## Before you submit

1. Search every page for `class="fill-in"`. Each match is a highlighted placeholder such as your name, section, or instructor. Replace the text inside it.
2. Once a placeholder is filled in, delete `class="fill-in"` from that tag so the gold highlight disappears.
3. To add your photo, save it as `assets/photo.jpg`. In `index.html`, replace `YN` inside the avatar with:
   `<img src="assets/photo.jpg" alt="Portrait of Your Name">`
4. Read the "My Insight" boxes, the Profile, and the Reflection. Change any detail that does not match your own experience.
